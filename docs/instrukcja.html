🎉 3. Tworzenie wydarzenia

Na dashboardzie kliknij + Create Event (górny prawy róg lub link w breadcrumb).

PoleOpis
Event NameNazwa wydarzenia (wymagane)
Event CategoryKategoria: Tech, Music, Business, Conference…

Start Date & TimeData i godzina rozpoczęcia (wymagane)

Cykl życia wydarzenia

Nowe wydarzenie startuje jako DRAFT (niewidoczne publicznie). Aby opublikować, kliknij pasek statusu „Draft – Click to Publish" na górze strony.

🚀 4. Getting Started – pierwsze kroki

Po wejściu w nowe wydarzenie zobaczysz stronę z listą kroków do wykonania przed publikacją.

  1. Add tickets – utwórz bilety w sekcji Tickets & Products
  2. Set up your event – uzupełnij szczegóły w Event Settings
  3. Connect with Stripe – podłącz konto do przyjmowania płatności
  4. Customize your event page – dostosuj stronę publiczną w Homepage Designer
Zielony znacznik ✅ przy kroku oznacza, że jest ukończony. Pasek postępu u góry pokazuje procent gotowości.

PoleOpis

Szczegóły zamówienia

Kliknij w zamówienie, aby otworzyć panel boczny z zakładkami:

  • View – szczegóły, podsumowanie, odpowiedzi na pytania, uczestnicy
  • Edit – edycja danych zamawiającego i notatek wewnętrznych
  • Refund – zwrot pełny lub częściowy + opcja anulowania
